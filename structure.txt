📌 Features
- Register vehicles
- View and search registered vehicles
- Manage parking slots
- Check available and occupied slots
- Park vehicles and assign slots automatically
- Record vehicle entry and exit times
- Calculate parking charges based on duration
- Generate parking receipts
- View parking history
- Search vehicles by registration number
- Generate daily revenue reports
- Track currently parked vehicles

🛠️ Tech Stack
- Python
- JSON
- Datetime
- UUID
- OS
